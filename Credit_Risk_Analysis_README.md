# 💳 Credit Risk Analysis using Machine Learning

A predictive model to assess loan default risk using customer application data and credit history.

## 📌 Problem Statement
Classify loan applicants as low or high credit risk based on demographic and financial features.

## 🛠️ Tools & Technologies
- Python, pandas, scikit-learn, matplotlib, seaborn
- Logistic Regression, Decision Tree, Random Forest
- Jupyter Notebook

## 📈 Features
- Data cleaning and preprocessing
- Feature engineering and correlation analysis
- Multiple model evaluation and comparison

## 📂 Repository Structure
- `Rohini_Credit_Risk_EDA_Final.ipynb`: Complete EDA and modeling
- `application_data.csv`, `previous_application.csv`: Input datasets
- `columns_description.csv`: Data dictionary
