# Credit Risk Analysis

Predicting loan default risk to classify applicants as low or high credit risk.

## Problem
Lenders need to identify risky applicants before approving loans. This project builds a classification model on customer data to support that decision.

## Approach
1. Exploratory data analysis (EDA) and data cleaning
2. Feature engineering
3. Model training: Logistic Regression, Decision Tree, Random Forest
4. Model evaluation and comparison

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook

## Files
- `credit_risk_analysis.ipynb`: full analysis and modeling

## How to Run
1. Clone the repo
2. Install dependencies: `pip install pandas numpy matplotlib seaborn scikit-learn jupyter`
3. Open the notebook and run all cells
